# Two-iPhone acceptance

Use the same newly exported, signed build on both phones and different Game Center accounts. No Club Hub server is needed. Repeat with A and B exchanging roles.

1. Both phones open in the Plaza. A invites B from Friends. B receives an in-app banner and an inbox card without opening another app or tapping Apple's notification. Join from the card. A stays host. Repeat with B inviting A.
2. Walk and sprint on both phones for 60 seconds; watch the other avatar move. Join while using the locker or sitting on a bench, then walk again. Each player emotes and sees the other's emote.
3. Type a custom sentence, punctuation, accented/non-Latin text and emoji in Party Chat. Complete existing chat setup if necessary. Send both directions; the message appears over its speaker in the Plaza and expires after eight seconds. Muted/blocked senders do not display bubbles. Parental restrictions still apply.
4. Put one person in the locker and another on an Online bench. Call Party moves everyone to that bench, including a phone without its own TV. Repeat while the recipient crosses a doorway. Start waits for the people called to arrive; host selects the map and starts normally. At least one appropriate gameplay display remains required.
5. Invite while B is in a match: retain the invitation in Friends, then show its banner on return to the Plaza. Exercise Not now, decline, cancel, expiry and retry. If available, add a third/fourth player; verify existing peers remain connected.
6. On both phones, swipe Home and return 20 times, including during incoming invites. Repeat with Control Center and screen lock, with and without an external display. The lobby resumes and controls work without relaunching. A match may pause or interrupt according to the existing multiplayer policy. Capture device crash logs if anything terminates unexpectedly.

Record device models, OS/build, accounts, connection types and results in GATE_RESULTS.md. Local test fakes and editor screenshots do not pass these hardware gates.
