# Asset sources

`SummerSky.png` and `ArchipelagoSky.png` were generated with the built-in GPT Image tool for this task. The first is a sky/reflection painting; the second is a coastal island panorama. Generation output is source art, not proof of implemented game quality. Actual proof is captured in Unity.

`CoastalPines.fbx` was authored procedurally in Blender5.2.2 by `source/build_pines.py`. It contains four opaque maritime-pine variants and matching reduced-detail meshes. Vertex colours, branches, geometry and silhouette are generated locally. No third-party model was downloaded for this task.

Existing game geometry, texture maps and scenery retain their existing provenance. This pass references the game's existing turf and limestone maps; it does not claim authorship of them.

The original sculpted archipelago mesh was rejected after actual game inspection and removed from shipped Resources. The panorama is used for the distant island layer instead; it is not a 3D reconstruction or a multi-angle capture.
