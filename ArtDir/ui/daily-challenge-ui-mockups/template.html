Your call before I build it

Four choices

The clip shows today's line

Everyone plays the same spots, so the video shows friends where the pin is and how you hit it. Wordle hid its answer; this would not.

My pick: share it anyway. Seeing it go in is the hook, and they still have to swing it.

Default shape

Wide matches the game on the TV. Tall fits TikTok, Reels and Stories, with the game uncropped in the middle.

My pick: Wide for Save and Messages, Tall picked automatically for TikTok and Instagram.

Where the link goes

A link that opens today's challenge in the app, and the App Store page if the game isn't installed. The address above is a placeholder.

Needs a domain or the App Store link from you.

Your face in it

The clip uses only game footage. Creators can still film themselves on a second phone and stack it, as you asked on 11-14.

My pick: game footage only for now.
